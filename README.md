# GaHeal Semiconductors - Ga2O3 Power Devices
BHASKAR ID: IN-1026-9561VU | Founder: Bhargavi Dhamma (Solo) | Vizianagaram, AP

## Problem
Silicon devices fail at high voltage & high temp in EV chargers & solar inverters.

## Solution
Gallium Oxide (Ga2O3) - 4.8eV bandgap, 8kV breakdown, 200C+ operation.

## What We Built
- Ga2O3 Schottky Diode Simulation
- Breakdown Voltage: 8kV
- Application: EV Fast Chargers, Solar Inverters
